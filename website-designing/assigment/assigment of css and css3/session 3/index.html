Concept: position: static vs position: absolute

position: static (Default): The element stays in the normal document flow. Surrounding elements respect its space, and properties like top, right, bottom, or left are completely ignored.

position: absolute: The element is removed from the normal layout flow completely. Surrounding elements collapse and behave as if it doesn't exist. It can now be explicitly positioned anywhere relative to its closest non-static parent container (usually styled with position: relative).

Real-World Example (WhatsApp Unread Badge):

  • The chat row container is set to position: relative.
  • The red/green unread message counter badge inside it is set to position: absolute with top: -8px; right: -8px;.
  • This positions the badge exactly at the outer corner of the chat row without pushing or disrupting the contact's name and message preview text.
